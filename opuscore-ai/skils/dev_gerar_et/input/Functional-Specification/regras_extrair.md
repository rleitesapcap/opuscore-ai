# Extraidos_da_EF

## Fonte
Extrair os campos abaixo da tabela "Especificação Funcional" (cabeçalho da EF).
Cada campo aparece no formato "Rótulo: Valor". Extrair o Valor após os dois-pontos,
até o fim da célula.

## Campos a extrair
- Projeto
- Fase do Projeto
- Autor
- Módulo
- Cenário empresarial
- Processo
- ID GAP
- Descrição GAP
